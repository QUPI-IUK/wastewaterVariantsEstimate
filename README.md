
<b>Wastewater surveillance without prior lineage classification for reliable real time SARS-CoV-2 variant identification</b>


This contains the code to produce SARS-CoV-2 fitness gain estimates (logK) based on genomic wastewater data containing single nucleotide variants (SNVs) in a VCF file format. Genomic wastewater data from three Swiss cities (Altenrhein, Zurich, and Geneva) was taken from the European Nucleotide Archive (ENA, Project Number: PRJEB44932). For a better signal detection, correlations between logk and time over two different time windows (21 and 42 days) are calculated. In addition, scripts for the calculation of the abundance of variants are inlcuded.
